            └── vehicle.ts           Shared TS types (mirrors backend/src/types/vehicle.ts)

Data flow:
  Swiftly GTFS-RT feed -> backend/poller (every ~15s) -> PostgreSQL
  PostgreSQL -> backend/API -> frontend (polls every ~15s) -> Leaflet map

Notes:
  - backend and frontend are independent npm projects (separate package.json/node_modules).
  - The poller and API currently run together in one Node process (backend/src/index.ts)
    for simplicity. They could be split into separate deployable services later if the
    polling workload ever needs to scale independently of the API.
